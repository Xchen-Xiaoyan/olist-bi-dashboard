# 指标体系与口径

## 数据范围与清洗

| 项目 | 口径 | 原因 |
|---|---|---|
| 分析窗口 | 2017-01-01 至 2018-08-31 | 2016 年仅零星订单;2018-09/10 数据被截断(合计 20 单) |
| 买家 | `customer_unique_id` | `customer_id` 每单一个(99,441 个 ID 对应 96,096 名真实买家) |
| 有效订单 | 状态 ∉ {canceled, unavailable} | 取消与缺货订单不计入 GMV |
| 评价 | 每单保留最新一条 | 547 单有多条评价 |
| 品类 | 补全 2 个缺失翻译;无品类商品归为"未分类" | 610 个商品无品类 |
| 无商品明细订单 | GMV 记为 0 | 775 单无 item 记录(多为取消/缺货) |

校验:商品级 GMV 合计 = 订单级 GMV 合计(`scripts/build_model.py` 内断言)。

## 数据模型(星型)

```
dim_date ──┐
           ├── fact_orders (订单粒度) ──── fact_order_items (商品粒度) ──┬── dim_product
dim_customer ┘                                                          └── dim_seller
cohort_retention (预计算同期群)   funnel_stage (漏斗环节,断开表)
```

## 指标定义(DAX,`指标` 表)

| 分组 | 指标 | 定义 |
|---|---|---|
| 规模 | GMV | 有效订单的 商品金额 + 运费 |
| | 订单数 / 买家数 | 有效订单数 / 去重买家数 |
| | 客单价 | GMV ÷ 订单数 |
| | 人均订单数 | 订单数 ÷ 买家数 |
| 增长 | GMV 环比 / 同比 | `DATEADD(-1, MONTH)` / `SAMEPERIODLASTYEAR` |
| | 新买家数 / 新买家 GMV 占比 | 买家首单的订单 |
| | 复购率 | 有 ≥ 2 笔有效订单的买家 ÷ 买家数 |
| 履约体验 | 准时送达率 | 实际送达日 ≤ 预计送达日 的已送达订单占比 |
| | 平均配送天数 | 下单到签收的天数 |
| | 平均评分 / 差评率 | 评分均值 / 1–2 星评价占比 |
| | 运费占比 | 运费 ÷ GMV |
| | 漏斗订单数 / 转化率 | 下单 → 支付审核 → 发货 → 送达 → 好评(≥ 4 星) |
| 品类 | 品类 GMV / 占比 | 商品粒度 GMV,占全品类比例 |
| 留存 | 留存率 | 首购后第 N 个月仍有下单的买家 ÷ 该首购月买家数 |

**GMV 拆解恒等式**:GMV = 买家数 × 人均订单数 × 客单价。用它判断增长来自"更多人买"还是"每人买得更多、更贵"。
